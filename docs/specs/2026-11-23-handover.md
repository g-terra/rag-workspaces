# Handover notes for the next agent

## Summary

Adds `docs/HANDOVER.md`: what the project is and what it must deliver, the architecture and decisions in
one screen, how to run and test it, the working rules written as plain process steps, what is merged, every
branch still in flight, and the remaining work in priority order. `AGENTS.md` now points to it at the top,
so an agent that only reads `AGENTS.md` finds it. No code changed.

## Why

The owner is moving the work from Claude Code to Google Antigravity on 2026-11-23. The state of the work
(in-flight branches, priorities, open questions) lived in chat threads that Antigravity cannot read. The
Superpowers rule (AGENTS.md rule 8) names Claude Code skills; the handover spells the same steps out so
another tool can follow them.

## Design

One Markdown file, `docs/HANDOVER.md`, linked from the first section of `AGENTS.md`. It points to the
long-lived docs (`docs/architecture.md`, `docs/decisions.md`, `docs/api-schema.md`, `docs/setup.md`,
`docs/api.md`, `flows/README.md`) instead of repeating them, and keeps only what they don't hold: the
in-flight branches, the priority list and the owner's open questions.

## Decisions and trade-offs

| Decision | Alternatives considered | Why this one |
| -------- | ----------------------- | ------------ |
| A file in `docs/`, linked from `AGENTS.md` | A `GEMINI.md`, or editing `AGENTS.md` itself | Antigravity reads `AGENTS.md`; one pointer keeps `AGENTS.md` about rules, not status |
| Status lives in a dated handover, not in `work-breakdown.md` | Mark progress in `work-breakdown.md` | The handover goes stale and should be deleted when the list is done; the plan should not |

## Interfaces and contracts

- **HTTP API**: None.
- **Configuration**: None.
- **Data**: None.
- **Langflow**: None.
- **Events and logs**: None.

## Operations

None. Delete `docs/HANDOVER.md` and its `AGENTS.md` pointer once the remaining list is done.

## Testing

`pnpm format:check` for the Markdown. By hand: every branch listed exists on `origin`
(`git branch -r`), and every linked doc exists.

## Out of scope and follow-ups

The work it lists: the admin UI stacks, the M5 and M6 backend items, the report and the demo video.

## Docs updated

`AGENTS.md` (pointer to the handover), `docs/HANDOVER.md` (new).
